webtuidb can work with other programs as well as with you: an AI assistant tab that writes SQL for the open
database, an MCP server that lets coding agents list connections and run queries under token scopes and your
approval, plugins that add your own commands (an external program or a JavaScript file), and a command line for
scripts, completion and bug reports. Each page covers the terminal and the browser.
