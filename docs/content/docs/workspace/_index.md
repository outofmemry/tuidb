The workspace is the frame around your data once a connection is open: the sidebar with the schema's objects, the tab bar, the main pane, the status line and the console. The terminal draws it with panes you move between with the keyboard; the browser draws the same parts with a connection switcher and a toolbar. These pages cover each part of that frame, how tabs and panes behave, the Open Anything finder, the console, background jobs, and the lock screen and settings editor.
